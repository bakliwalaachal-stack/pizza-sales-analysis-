# pizza-sales-analysis-
Pizza Sales Data Analysis using SQL (Week 1 &amp; 2)
This project focuses on analyzing pizza sales data to uncover key business insights such as revenue trends, customer ordering patterns and product performance.
PROJECT STATUS- (week 1 and week 2 Completed)

Week 1 - Data cleaning and pre-processing 
handled missing and null values
standardized date and time formats 
remove duplicate records
cleaned inconsistent entries in columns. 

Week 2 - SQL Analysis(Performed SQL based queries to understand key business questions such as - 
TOTAL REVENUE GENERATED
TOTAL NUMBER OF ORDERS
ORDERS PER DAY
TIME ANALYSIS(PEAK HOUR PERFORMANCE)
TOP SELLING PIZZAS
BEST PERFORMING CATEGORIES
LEAST SELLING ITEMS 

Tools and Technologies used- 
SQL
Excel

Key learnings- 
Importance of DATA CLEANING before analysis
Writing efficient SQL queries for proper business insights

Week 3 - Dashboard Creation using Power BI 
- Built interactive dashboard
- Visualize KPI's like total sales,orders and revenue.
- Created charts for category-wise and size-wise distribution.
- Added filters for better insights.

Key Insights :
1.Classic pizzas contributed the highest sales.
2.Large sized pizzas were most prefered.
3.Peak orders were during weekends & evening hours.

CONCLUSION - The analysis helped identify customer preferences and peak demand periods.These insights can help optimize 
menu offerings,pricing strategies and marketing campaigns to increase revenue.
